# v1.0.4 审核报告

## 调度全链路审核结果

### 核心机制

| 机制 | 实现 | 状态 |
|------|------|------|
| 粘性优先调度 | 锁定主账号持续使用，不可用才轮转 | ✅ 稳定 |
| 阈值自动换号 | 每次请求从 `usage.credit` 预扣本地额度，低于阈值自动禁用+切号 | ✅ 闭环 |
| 冷却分级 | 429→quota(1h)、403→auth(10min)、401/502/503/504→transient(1min) | ✅ 对齐官方 |
| 冷却持久化 | settings表JSON存储，重启自动恢复，到期自动释放 | ✅ 无丢失 |
| 最后号保护 | `on_disable` 先验证池中有备选再写DB，否则拒绝操作 | ✅ 防锁死 |
| 无备选阈值触发 | 不禁用不切号，只提示一次（`_threshold_no_fallback` 布尔锁） | ✅ 无死循环 |

### 不阻塞 / 不死锁 / 不需重启

| 检查项 | 结论 |
|--------|------|
| RLock 可重入 | 持锁期间仅内存操作 + 微秒级 SQLite 写，无网络 IO |
| `_stream_inner` 重试有界 | `max_attempts = max(count_usable(), 1)`，不会无限循环 |
| 每个 `resp` 都有 `aclose()` | try/finally/except 全覆盖，无连接泄漏 |
| `deduct_quota` 在 finally 执行 | 客户端断连也不丢统计 |
| 并发请求 `_active_count` 计数器 | 不会因一个请求结束误判全局 inactive |
| `proxy_stop` 重置 `_active_count=0` | 停止后状态干净 |
| SQLite WAL 模式 | 每操作独立连接，读写不阻塞 |
| 日志自动裁剪 | 5000 行上限，无膨胀 |

### 凭证同步

| 场景 | 凭证更新方式 |
|------|-------------|
| 阈值切号 | `deduct_quota` → 禁用旧号 → `_current_id` 切新号 → 下次 `get_next()` 返回新号 `access_token` |
| 手动禁用当前号 | `on_disable` → 内存标记 disabled → `_current_id` 切新号 → 下次请求自动用新凭证 |
| 刷新 token | `refresh_token` → 写库 → `reload()` → 代理立即用新 `access_token` |
| 手动启用 | `clear_disabled` + `reload` → 账号恢复可用 |

### UI 同步

| 事件 | 同步方式 |
|------|---------|
| 阈值切号 | `pollProxyInfo`(2s) → 检测 `current_account` 变化 → `updateAccountHighlight` 移动徽章 + `loadAccountsLight` 刷新卡片 |
| 请求结束 | `pollProxyInfo` 检测 active→false → `refreshAccountStats` 拉最新 token 统计 |
| 手动禁用/启用 | `toggleAccountStatus` → `refreshProxyStatus` + `loadAccounts` 全量刷新 |
| dev 模式刷新页面 | `startApp` → `loadAccounts`(重试) → `refreshProxyStatus` → 恢复轮询+动画 |

### 额度计算

| 数据源 | 用途 |
|--------|------|
| 官方 API `get-user-resource` | 刷新时拉取，写入 `quota_raw` |
| `parse_resources()` | Status∈{0,3} 过滤 + 套餐合并(006+008, 009) + `is not None` 判空 |
| `usage.credit` | 每次请求成功后从 SSE 流提取，预扣 `_estimated_remain` |
| `account_stats.total_credit` | 代理期间累计消耗，刷新时清零（API 已包含） |
| `account_stats.lifetime_credit` | 永久累计，刷新不清零 |

### Token 统计（永久持久化）

| 字段 | 说明 |
|------|------|
| `prompt_tokens` | 累计输入 Token |
| `completion_tokens` | 累计输出 Token |
| `total_tokens` | 累计总 Token |
| `lifetime_credit` | 永久消耗积分（刷新不清零） |
| `cache_hits` / `cache_misses` | 缓存命中/未命中（命中率 = hits/(hits+misses)） |
| `request_count` | 代理处理的请求次数 |

### 已知限制（非 Bug）

- 官方 API 额度查询有延迟，本地预扣比 API 更实时
- dev 模式刷新页面时 pywebview 回调丢失（控制台报错，不影响功能）
- 打包 exe 无此问题

## 结论

v1.0.4 调度全链路审核通过，无阻塞、无死锁、无需重启恢复的问题。
